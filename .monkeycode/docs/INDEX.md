# 抵达 Focus 项目文档

## 项目概述

抵达 Focus 是一款面向 Windows 10/11 的本地优先桌面专注系统，帮助个人用户在长期项目、每日计划、深度专注与周期复盘之间建立连续工作流。

**目标用户**：需要在 Windows 电脑上完成学习、创作、编程和知识工作的个人用户。

**核心价值**：

- 用任务与专注轮次建立明确的当下行动。
- 用项目和重复计划连接长期目标与每天执行。
- 通过系统托盘、后台计时和原生提醒降低操作中断。
- 通过桌面小组件在开机后持续呈现今日行动。
- 通过本地数据库和可移植备份保障离线能力与数据自主权。

## 技术选型

| 类别 | 选择 | 理由 |
|------|------|------|
| 桌面框架 | Tauri 2 | 支持 Windows 原生外壳、较小安装体积和受控系统权限 |
| 前端 | React + TypeScript + Vite | 适合复杂交互界面与类型化领域模型 |
| 原生层 | Rust | 负责生命周期、托盘、通知、快捷键和可靠计时 |
| 数据存储 | SQLite | 支持事务、迁移、查询统计和可靠恢复 |
| 样式 | 共享 CSS + Design Tokens | 支持四套主题、明暗模式和主窗口/小组件一致语义令牌 |
| 测试 | Vitest + React Testing Library + Playwright + Rust tests | 覆盖领域逻辑、组件、桌面流程和原生命令 |
| 安装包 | NSIS | 提供 Windows 常见安装流程和灵活安装选项 |

## 核心功能

当前代码已完成 Tauri 双窗口工程骨架、类型化命令结果、窗口 capability、响应式主窗口外壳、桌面小组件配置生命周期与 Windows Shell 贴附适配器、共享 UI 设计体系、长期项目领域，以及任务与检查项读写、筛选查询、任务编辑器、五态任务行和今日工作台。任务领域和组件测试已覆盖日期校验、状态转换、项目关联、筛选与键盘焦点；重复计划已具备结构化规则、日期展开、幂等实例生成、缺失日期补生成、实例操作、自然语言摘要、规则编辑器和范围变更对话框，并通过 P1 属性测试验证重复生成下的实例唯一性、通过 P2 属性测试验证任意有效规则与日期范围的输出确定且严格有序、通过 P3 属性测试验证未来规则变更保持历史实例稳定；`TodayDigest` 已贯通 Rust 聚合服务与 React 今日界面，统一呈现普通任务、项目任务、重复实例和逾期事项，并通过 P4 属性测试验证全部符合条件来源均被纳入且每个来源只出现一次。专注空间通过 P6 属性测试验证系统恢复后的计时校准；日历复盘已接入周、月、年自然周期查询，按查询时区聚合普通任务、重复实例、完成记录与有效专注轮次，并提供分类、项目筛选和日期详情。统计服务复用日历完整日序列计算计划完成率、完成任务数、专注分钟、有效轮次、活跃天数和项目投入，前端同步展示周期摘要、完成与专注趋势、项目投入及零数据行动入口。今日 planning 模块已提供按日期持久化的便签、500ms 自动保存、`Ctrl+Enter` 立即保存和反馈，并支持按完成任务、专注分钟与活跃天数创建周目标；周目标复用自然周统计结果，在任务或有效专注变化后延迟 250ms 重新读取并保存封顶进度。小组件支持三档尺寸、模块选择、透明度、窗口几何信息、显示器、DPI、模式和锁定状态的本地持久化与事件同步，并可发现 WorkerW 宿主、恢复失效附着和回退普通浮窗。普通浮窗原生置顶，锁定状态固定尺寸并启用鼠标穿透，顶部拖动区、原生缩放和托盘解锁入口组成完整恢复路径。三档小组件界面分别承载 1、5、10 项任务容量，展示时钟、当前专注、今日进度、任务时间、标题、项目、重复和逾期信息，并复用现有命令完成任务、启动或控制专注及延后重复实例。系统托盘现已展示当前或下一任务、权威剩余时间，并提供主窗口、小组件、计时、快速任务、解锁和退出操作；主窗口关闭后依据持久化后台运行偏好隐藏到托盘或直接关闭。Windows 原生通知已覆盖专注完成和定时任务到时，支持默认启用的提示音、系统权限入口、投递记录去重、休眠恢复补偿和设置页开关，并通过 P7 属性测试验证重复处理专注完成、普通任务到时和重复实例到时事件时每个业务身份只产生一条投递记录。统一设置服务通过 `generalPreferences` JSON 偏好管理系统/中英文语言选择、系统/浅色/深色外观、四套主题和后台运行，并通过 `settings://changed` 将完整通用偏好同步到主窗口与小组件；设置页组合通知提示音、开机启动、快捷键、小组件模式、尺寸、透明度、锁定、显示模块和本地数据入口。以下业务功能是已确认的首版范围，将按实施计划逐步接入。

重复计划、今日汇总、专注空间、日历与统计复盘、便签与周目标、桌面小组件、系统托盘、Windows 通知、统一设置、全局快捷键、开机启动与任务栏进度阶段均已通过 Rust、前端、静态检查和生产构建门禁。当前基线为 119 项 Rust 核心库单元测试、3 项 Windows 适配器集成测试和 68 项前端测试。设置测试覆盖默认值、Patch 字段保留、SQLite 往返、组件保存失败、系统明暗解析，以及主窗口和小组件的共享事件同步。统计服务测试覆盖真实跨越本地午夜的专注归属、完整零数据趋势和项目筛选后的任务、专注与投入聚合；周目标服务测试覆盖关联数据变化后的三类指标重算、目标封顶和数据库回写。窗口恢复通过 P8 属性测试覆盖任意有效保存矩形与非空显示器集合，主要操作区越界时回到主显示器安全区域；Windows 适配器集成测试覆盖附着、Explorer 重启、浮窗回退和解锁恢复。

### 今日工作台

- **目的**：组织当天最重要的行动。
- **描述**：当前已提供动态周日期条、分类任务分区、完成状态筛选、定时日程、周目标和便签区域。桌面运行时通过 `TodayDigest` 读取选中日期的普通任务、项目任务、重复实例和逾期事项，并按来源分发普通任务与实例操作；便签按选中日期自动保存，周目标按自然周保存名称、指标分类和数量，并从任务与有效专注统计自动重算进度。

### 长期项目

- **目的**：持续管理由多项任务组成的长期工作。
- **描述**：提供项目概览、任务分组、进度、截止风险、近期活动和专注投入。

### 重复计划

- **目的**：把周期性工作自动转化为每天可执行的行动。
- **描述**：当前模型支持每天、工作日、每周指定星期、每月指定日期和自定义间隔，并校验本地执行时间、IANA 时区及有效日期范围。任务编辑器可创建重复规则并即时展示自然语言摘要；今日页通过范围对话框支持仅修改本次或未来计划。实例服务与界面支持完成、跳过、今日延后、顺延明日、暂停和结束规则。

### 专注空间

- **目的**：围绕一个任务完成稳定专注轮次。
- **描述**：当前已提供 15、25、50 分钟预设和 1–180 分钟自定义时长、任务选择、大号倒计时、暂停、继续、重置、提前完成确认、最近轮次及输入焦点避让的空格快捷键。桌面运行时使用 Rust 权威状态并监听完成事件；系统托盘可启动、暂停和继续轮次，后台线程持续校准并完成到期轮次。Windows 任务栏在运行时显示剩余比例，暂停时切换暂停状态，轮次结束后清除进度。

### 日历复盘

- **目的**：将任务结果和专注投入转化为可观察趋势。
- **描述**：当前已提供周、月、年自然周期视图，完整返回周期内零数据日期，并按查询时区将计划任务、完成任务和有效专注轮次归入本地日期。界面支持分类与项目筛选、周期导航、活动标记和日期详情，并展示计划完成率、完成任务数、专注分钟、有效轮次、活跃天数、完成与专注趋势及项目投入；年度趋势按月汇总，零数据周期提供专注入口。

### Windows 桌面集成

- **目的**：让专注工具融入日常电脑工作流。
- **描述**：当前已实现桌面 WorkerW 贴附、Explorer 宿主失效恢复、普通浮窗回退、浮窗置顶、拖动缩放、锁定鼠标穿透、完整托盘控制、关闭到托盘，以及专注完成和任务到时原生通知；通知提示音可配置，设置页提供 Windows 权限入口。设置页可配置显示主窗口、控制专注、创建快速任务和解锁小组件四项全局快捷键，并即时同步 Windows 登录启动项。

### 本地数据管理

- **目的**：提供稳定、离线且可迁移的数据能力。
- **描述**：使用 SQLite 持久化数据，提供 JSON 备份、校验恢复、自动快照和数据库迁移。

## 首版边界

首版采用纯本地单用户模式，目标平台为 Windows 10/11 x64。账户、云同步、团队协作和强制应用限制进入后续版本评估。
