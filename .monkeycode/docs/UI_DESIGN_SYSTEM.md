# 抵达 Focus UI 设计体系

## 设计定位

抵达 Focus 延续参考站点“抵达”的低饱和、克制和陪伴感，并把视觉体系扩展到长期项目、重复计划和 Windows 桌面小组件。整体体验强调明确的下一步、稳定的时间感和完成后的落点。

参考站点提供了四项关键视觉资产：232px 固定侧栏、20px 圆角轻面板、超大等宽计时数字、薄荷主题与像素伙伴。抵达 Focus 保留这些识别点，并通过更强的信息层级解决项目和定时任务密度增加后的可读性。

## 设计原则

### 当下优先

每个页面提供一个最高层级行动。今日页突出下一项任务，项目页突出当前里程碑，专注页突出剩余时间，小组件突出现在与接下来。

### 长期可见

项目颜色、项目进度和截止风险贯穿任务卡片、今日汇总、日历与小组件，让每天行动保持长期上下文。

### 安静陪伴

常态界面使用低饱和背景、细边框和短动效。逾期、冲突和数据错误使用高辨识状态色，并配合文字标签。

### 桌面原生

窗口尺寸、密度、键盘操作、系统主题和多显示器行为遵循 Windows 使用习惯。小组件在信息完整度和桌面占用之间提供明确档位。

## 品牌语言

- 产品中文名：抵达 Focus。
- 英文标识：Arrive Focus。
- 核心文案：今日所做，皆为抵达。
- 行动文案：先完成眼前这一小步。
- 项目文案：让每天的进展汇入长期目标。
- 定时任务文案：固定的行动，会在今天准时出现。

## 色彩令牌

颜色使用 OKLCH 定义，主题通过语义令牌映射。状态表达同时包含图标或文字。

```css
:root {
  --color-canvas: oklch(0.975 0.012 184);
  --color-surface: oklch(0.995 0.004 184);
  --color-surface-muted: oklch(0.955 0.018 184);
  --color-text: oklch(0.285 0.025 205);
  --color-text-muted: oklch(0.53 0.02 205);
  --color-border: oklch(0.89 0.018 184);
  --color-accent: oklch(0.67 0.105 177);
  --color-accent-strong: oklch(0.52 0.105 177);
  --color-focus-ring: oklch(0.7 0.13 220);
  --color-success: oklch(0.66 0.13 151);
  --color-warning: oklch(0.73 0.14 77);
  --color-danger: oklch(0.62 0.19 28);
  --color-info: oklch(0.64 0.12 246);
}
```

四套主题只替换画布、强调色和装饰渐变：

| 主题 | 主色倾向 | 使用情境 |
|------|----------|----------|
| 薄荷序章 | 柔和青绿 | 默认日常专注 |
| 黑金沉浸 | 炭黑与暖金 | 夜间深度工作 |
| 办公蓝 | 雾蓝与深海蓝 | 项目管理与正式工作 |
| 粉红柔光 | 灰粉与莓红 | 轻量计划与生活任务 |

项目允许用户从 12 个中等饱和色中选择标识色。项目色只用于 3px 侧边标、图标底色、进度条和标签，避免整块高饱和背景。

## 字体体系

- 标题：`Avenir Next`, `Segoe UI Variable Display`, `Microsoft YaHei UI`, sans-serif。
- 正文：`Segoe UI Variable Text`, `PingFang SC`, `Microsoft YaHei UI`, sans-serif。
- 数字：`Cascadia Mono`, `SFMono-Regular`, `Consolas`, monospace。
- 大计时：82–146px，字重 500，行高 0.95。
- 页面标题：28px，字重 650，行高 1.25。
- 卡片标题：16px，字重 650，行高 1.4。
- 正文：14px，字重 400，行高 1.6。
- 辅助文字：12px，字重 500，行高 1.5。

## 间距与形状

- 基础间距单位：4px。
- 常用间距：4、8、12、16、20、24、32、40、48px。
- 控件高度：紧凑 32px、默认 40px、强调 48px。
- 卡片圆角：16px；主面板 20px；专注舞台 28px；对话框 22px。
- 小组件圆角：18px；紧凑模式 14px。
- 边框：1px 语义边框色。
- 阴影：常态 `0 8px 30px color-mix(in oklch, var(--color-text) 8%, transparent)`。

## 布局体系

### 主窗口

- 最小尺寸：1024 × 680。
- 默认尺寸：1360 × 860。
- 侧栏：232px，包含品牌、今日、项目、专注、日历和设置。
- 主内容最大宽度：1560px，页面内边距 32px。
- 今日页：260px 周目标栏、弹性任务区、300px 日程与便签栏。
- 项目页：280px 项目导航、弹性项目工作区、320px 洞察栏。
- 专注页：弹性专注舞台、320px 当前任务与轮次记录栏。
- 日历页：280px 统计栏、弹性日历与日期详情区。

### 桌面小组件

| 模式 | 默认尺寸 | 内容 |
|------|----------|------|
| 紧凑 | 320 × 132 | 时钟、当前专注、下一项任务 |
| 标准 | 360 × 420 | 时钟、今日进度、前 5 项任务、快速操作 |
| 展开 | 440 × 640 | 前 10 项任务、项目进度、周目标和便签入口 |

小组件顶部 28px 区域作为解锁状态拖动区。锁定状态隐藏编辑控件并启用鼠标穿透。边缘悬停解锁采用全局快捷键或托盘入口，保证穿透状态可恢复。

## 信息层级

今日任务卡采用固定顺序：完成控件、时间、任务标题、所属项目、重复标签、专注入口。逾期状态显示具体逾期时长。项目任务使用项目色侧边标；重复任务显示循环图标与规则简称。

项目卡展示项目名称、状态、截止日期、任务完成比例、累计专注时长和下一项任务。项目详情使用“概览、任务、活动、统计”四个标签页。

## 核心组件

### TaskRow

- 支持普通、当前、完成、逾期、暂停五种状态。
- 主操作区域点击打开详情，完成按钮和专注按钮拥有独立点击区域。
- 时间固定宽度 52px，标题允许两行，小组件模式压缩为一行。

### ProjectCard

- 使用 3px 项目色侧边标。
- 进度条同时显示百分比和完成数量。
- 截止风险使用“剩余天数”或“逾期天数”文字。

### FocusStage

- 计时数字保持页面最高视觉层级。
- 运行状态使用 5.6 秒低幅呼吸光晕。
- 暂停状态停止呼吸并降低强调色明度。
- 遵循 Windows 减少动态效果设置。

### RecurrenceBadge

- 使用循环图标与“每天”“工作日”“每周一”“每月 15 日”等短文本。
- 编辑器使用自然语言摘要即时回显完整规则。

### TodayProgress

- 展示已完成数量、总数量和圆环进度。
- 逾期数量单独显示，保持总进度定义稳定。

## 动效与反馈

- 常规过渡：160ms，`cubic-bezier(0.2, 0, 0, 1)`。
- 面板展开：220ms。
- Toast：停留 1800ms，错误信息保持到用户关闭或 6000ms。
- 任务完成：勾选、文字淡化和列表位置变化在 240ms 内完成。
- 专注呼吸：5600ms 循环，缩放幅度控制在 1.5%。
- 减少动态效果模式将装饰动画时长设置为 0ms，保留焦点和状态颜色反馈。

## 无障碍

- 正文与背景对比度达到 4.5:1，大文字达到 3:1。
- 所有图标按钮提供可读名称和工具提示。
- 键盘焦点使用 2px 外环与 2px 偏移。
- 主要触控与鼠标目标最小 40 × 40px，小组件紧凑操作最小 32 × 32px。
- 颜色状态同时提供文字、图标或形状提示。
- 页面支持 125% Windows 文本缩放，关键操作保持在可视区域。

## 文案规范

- 操作按钮使用动词：开始专注、完成任务、延后、跳过本次。
- 时间使用明确表达：今天 10:00、明天、逾期 2 天。
- 删除和替换数据使用结果描述与影响范围。
- 空状态提供一个明确入口，例如“创建第一个项目”。
- Toast 描述已发生结果，例如“今天这次任务已完成”。
