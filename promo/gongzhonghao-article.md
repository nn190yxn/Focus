# 我洗了 100 个番茄，最终还是回到了本地软件。

自从「专注」「心流」「番茄钟」这些概念火起来之后，我基本把市面上能叫得出名字的专注 App 都试了一遍。

要说功能，真没太大区别。倒计时、任务列表、统计图表——大家都差不多。

区别在感觉。

用网页版，总会被边上那个新打开的标签拉走。用手机 App，微信通知一弹，心流就断了。用那些「All in One」的全家桶，光是配置项目、标签、视图、集成就能消磨掉我本来要专注的那半个小时。

真正让我烦的，是另一种感觉：**我的注意力数据不归我。**

你用过的每一个任务、每一次计时、每一次中断、每一次复盘，都在别人的服务器上。你关掉订阅，它们就消失。你换个工具，它们带不走。

慢慢地我意识到一个问题——**专注这件事，需要的不是更多功能，而是一个不会背叛你的工具箱。**

「抵达 Focus」就是照这个想法做的。

---

## 它是什么

一个跑在 Windows 桌面上的专注系统。叫「系统」而不是「App」，因为它不是只帮你计时的番茄钟，而是把 **项目、计划、专注、复盘** 串成了一条线。

你用它的流程大概是这样的：

1. 建一个长期项目——比如「写一门 Rust 课」或「跑完一场半马」
2. 每天早上，把今天要推进的事项拖进「每日」面板
3. 打开专注计时器，选一个时长，开始干活
4. 每周末，打开统计页看一眼：这周真正干活的时间有多少，都花在哪了

这四条线——项目、每日、专注、复盘——是互相咬合的。项目给每天提供方向，专注给每天提供深度，复盘让下一周更清醒。

它还有一个桌面小组件，透明玻璃质感，可以锁定在屏幕角落。你随时瞄一眼就能看到今天还有哪些要做，不需要切窗口。

---

## 为什么是「本地优先」

这不是一个技术选型，是一种设计哲学。

「抵达 Focus」的所有数据——项目、任务、备忘、专注记录——全部存储在你电脑的 SQLite 数据库里。没有云同步，没有在线账号，没有服务器。

打开就能用。离线就是正常态。

这意味着几件事：

- 你的数据 100% 归你。你随时可以把数据库文件拷走，换台电脑继续用；
- 没有订阅费。不是「试用 14 天然后每月 29 块」那种；
- 没有数据泄露的可能。因为数据根本没离开你的硬盘。

我知道有人会问：「那换电脑怎么办？」

目前的方案是直接复制数据库文件。之后会加入本地网络同步或手动备份还原。但永远不会把数据强行上传到某个中心服务器。

这是底线。

## 还有更多功能

除了核心的「项目-每日-专注-复盘」四条线，「抵达 Focus」v0.1.5 还包含许多实用的细节：

**备忘与提醒**：可以为重要事项添加备忘，设置时间提醒，支持重复提醒（每天、每周等）。提醒会被推送到 Windows 原生通知系统，不用盯着屏幕等。

**标签与搜索**：给备忘和任务打标签，支持模糊搜索和标签过滤。信息多了也不乱。

**日历视图**：支持月视图、周视图、年视图切换，一目了然地查看你每天的时间投入分布。

**数据导出**：支持将专注记录、项目数据导出为 JSON 格式，方便用其他工具做二次分析或迁移。

**全局快捷键**：可以设置全局热键快速呼出或隐藏应用窗口，不打断当前工作流。

**开机自启**：可选的启动项，开机后自动在后台待命，需要时一键唤出。

**小组件置顶**：桌面小组件可以锁定在最顶层，不会被其他窗口遮挡，随时了解今日待办。

---

## 一个有意思的细节

在「抵达 Focus」里，专注计时一旦开始，你可以把它最小化，但不能暂停。

这是刻意的。

真正的专注不是「累了就暂停、歇够了再继续」——那样一天能有 30 分钟真正专注就不错了。真正的专注是你定好 45 分钟，这 45 分钟内你不能退出。你只能把它缩小到角落，然后继续干活。

45 分钟到了，它会提醒你。弹窗会问你：这段时间你完成了什么？你输入一段话，它记录下来，成为你下周复盘时的数据点。

这个设计很小，但我觉得它抓住了专注的本质：**专注不是放纵自己随时停下，而是给自己一个不能反悔的承诺。**

## 技术

抵达 Focus 基于 Tauri 2 + Rust，前端用 React 19 + TypeScript。

安装包只有 4.7 MB。

---

## 下载

完全免费，在 GitHub 上开源。

下载地址：https://github.com/nn190yxn/Focus/releases

提供三种安装方式——NSIS 安装包、MSI 部署包、便携版主程序。

SHA-256 校验值见 Release 页面的 SHA256SUMS.txt。

当前版本尚未进行 Authenticode 签名，Windows 首次运行时可能会弹出 SmartScreen 提示。请核对发布者仓库和 SHA-256 数值后放行。

## 最后

我见过太多人——包括我自己——在各种工具间迁徙。今天用 Notion，明天用 Todoist，后天用 TickTick。每换一次，所有的历史数据都变成一堆无法迁移的废墟。

抵达 Focus 想做的是让你停下来。

让你不必再四处寻找「更好的工具」，因为这个工具是你的，数据是你的，习惯也是你的。

它的设计是「安静」的——不妨碍你专注，不刷存在感，也不需要你每天打卡签到。

你只需要打开它，定好今天要做什么，开始计时，然后干活。

**专注当下，抵达长期。**
