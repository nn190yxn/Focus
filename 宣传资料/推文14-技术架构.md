# 推文 14：Tauri 2 + Rust —— 为什么一个效率工具只有 4.5 MB

## 你电脑上最臃肿的软件，往往不是功能最多的那个。

打开任务管理器，看看你的效率工具占了多少内存。Todoist 的桌面端基于 Electron，一个本质上运行着完整 Chromium 浏览器的壳，内存占用轻松突破 300MB。Notion 桌面端同样基于 Electron，启动时间以秒计。

效率工具占用大、启动慢、吃内存——这已经成了默认状态，以至于我们习惯了。

抵达 Focus 做了一个不同的技术选择：**Tauri 2 + Rust。**

Tauri 2 是 Rust 生态下的桌面应用框架。它不使用 Chromium——它直接使用操作系统的原生 WebView（Windows 上使用 WebView2）。这意味着：

- **安装包只有 4.5 MB。** 不是 150MB。
- **启动时间 < 1 秒。** 不是 5 秒的 loading 画面。
- **空闲内存占用约 30MB。** 不是 300MB。

底层用 Rust 处理所有性能敏感的路径：数据库操作、文件读写、系统通知、快捷键注册、窗口管理。前端用 React + TypeScript 构建 UI。

这个技术栈不需要你了解。你只需要知道：**它用起来很快，而且不会拖慢你的电脑。**

另外，因为 Tauri 使用操作系统的原生 WebView，它的窗口行为更像一个「真正的 Windows 应用」——而不是一个套壳的网页。窗口大小调整、最小化还原、任务栏缩略图、右键菜单，都是原生的。

这是技术上的「少即是多」。选择更少的依赖、更小的体积、更快的速度，换来更流畅的体验。
