# 推文 09：数据属于你 —— 本地优先，开源，免费

## 你的数据不属于任何一个云服务。它属于你。

市面上的效率工具绝大多数是 SaaS。你用的每一个功能背后都有一个数据库在云端，有工程师在维护，有投资人期望增长。

这没什么不对。但你的待办事项、项目计划、专注记录、私人笔记——这些数据被放在一个你无法直接访问的服务器上。当服务停止运营、修改定价策略、或被收购时，你的工作流也随之断裂。

抵达 Focus 从设计第一天就选择了另一条路：

**所有数据存储在本地的 SQLite 数据库。** 没有云同步，没有用户账户，没有服务器。数据以开放的 SQLite 格式存储，你可以用任何数据库工具直接读取。

**完整的数据备份和恢复。** 一键导出所有数据为 JSON 文件（人类可读的开放格式）。恢复数据前会自动创建当前数据快照，防止误操作覆盖。包含格式校验和引用完整性检查，确保备份文件不会损坏你的数据。

**开源，完全公开。** 基于 Tauri 2 + Rust，代码托管在 GitHub。你可以审查每一行代码，确认它没有在你的本地数据库之外传输任何数据。有编程能力的用户甚至可以自己从源码编译。

**永久免费。** 不提供付费版，没有「Pro」功能，没有订阅，没有广告。这不是商业模式的选择——这是一个立场：个人效率工具不应该用数据变现。

安装包 4.5M，下载后即可使用。不需要联网注册。

你的数据，你做主。
