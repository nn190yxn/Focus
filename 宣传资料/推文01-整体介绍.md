# 推文 01：整体介绍 —— 把方向、计划、专注、复盘串成一条线

## 抵达 Focus：开源的桌面专注系统，让「做完一件事」成为默认状态

我们每天都在被各种任务管理器、番茄钟、日历、备忘录包围。

但它们之间是断裂的。

你需要在 Todoist 里列任务，在番茄钟里计时，在备忘录里写笔记，在日历里做规划。每个工具都在自己的世界里运转，唯独不在你的工作流里。

抵达 Focus 想做的，是把四条线合在一起：

**项目 → 每日计划 → 深度专注 → 周期复盘**

你创建项目时，它会问你：这件事的终点在哪？然后根据项目任务自动生成今日待办。每天开始工作时，从今日列表里挑一件事，点击进入深度专注。计时结束时，它问你「这段时间完成了什么」，这句话会成为你下一周回过头看自己是否虚度时光的数据点。

全程没有广告、没有订阅、没有社交功能。数据存在本地，你拥有每一条数据的所有权。

这是开源软件，在 GitHub 上完全可见。安装包 4.5M，启动 0.8 秒。不是因为它简单，而是因为用 Rust 重写了所有底层逻辑，用 Tauri 替代了 Electron 的臃肿。

如果你想要一个「不打扰你、但永远在那」的效率助手——试试抵达 Focus。

https://github.com/nn190yxn/Focus
